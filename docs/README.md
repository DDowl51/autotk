# 文档入口

当前 2.0 文档只保留以下主入口。部署、测试或排障时先从这里选，不要沿用旧 mobile、坐标标定、组合查询或历史交付清单。

| 要做什么 | 唯一入口 |
|---|---|
| 从零部署、运行冒烟/工作流、收集证据、反馈问题 | [`真机部署手册.md`](真机部署手册.md) |
| 记录每轮真机结果或提交可复现问题 | [`真机联调-checklist.md`](真机联调-checklist.md) |
| 查看当前完成度、缺口与已验证边界 | [`项目进度报告.md`](项目进度报告.md) |

| 查看已拍板决策 | [`决策记录-2026-07-20.md`](决策记录-2026-07-20.md) |

## 文档维护规则

- 命令级部署、工作流测试和排障步骤只写入 `真机部署手册.md`。
- 当前完成度只写入 `项目进度报告.md`，测试数字必须来自当次实际运行。
- 真机结论必须附测试记录；离线测试通过不能写成真机已通过。
- 历史方案若已被当前决策取代，直接删除或在决策记录中保留结论，不再新增平行“最新版/最终版”文档。
- `apps/mobile` 已退役；其目录内文档只作考古，不属于 2.0 部署入口。
