# 真机操作清单（只有真机/真环境能做和能测的事）

分三块：**A 每台手机装机与一次性设置**、**B 手机重启后恢复**、**C 交付前必须真机验的测试项**。
后端部署见《部署清单-完整.md》；这份专管手上有真 iPhone + 电脑时要做/要验的。

> 判定约定：每个测试项都写清「**测什么 / 判过 / 判败 / 失败后果**」，别只跑一遍看着像好了就算过。

---

## A · 每台手机装机与一次性设置（新机做一遍）

按顺序，缺一步后面连不上：

1. **装 WDA**（底层驱动，黑屏小工具）
   - 买家自助：手机 Safari 开 `https://〖install.你的域名〗/ota/autotk` 同页装 WDA；或卖家用 go-ios 装。
   - 装后：设置 → 通用 → VPN与设备管理 → **信任开发者证书**；设置 → 隐私与安全性 → **开发者模式** → 开 → 重启。

2. **激活 WDA**（挂开发者镜像，让 WDA 能跑）
   - ⚠️ 电脑需先装 **iTunes / 「Apple 设备」App**（苹果 USB 驱动，否则连不上手机、也不弹「信任此电脑」）。
   - 手机连电脑、解锁、点「信任此电脑」。双击电脑上的「激活WDA」→ 点「① 激活手机 WDA」→ 等 ✅ →
     手机上点开 WDA 图标（出现两行英文即成功）→ 拔线。
   - 验证：电脑 `curl http://<手机IP>:8100/status` 返回 ready（或 autotk 点启动不报连接失败）。

3. **装 autotk**：同一装机页 `https://install.域名/ota/autotk` 装 → 信任开发者（同 WDA）。

4. **激活 autotk**：打开 autotk → 输入激活码 → 激活成功进主界面。（一码一机，除非买多设备码。）

5. **授定位权限「始终」**（后台保活的命脉）
   - 首次点「启动」会弹定位授权 → **必须选「始终允许」**。
   - 点错了：设置 → 隐私与安全性 → 定位服务 → autotk → 改「始终」。
   - ⚠️ 只给「使用App时」= 后台会被挂起、养号会停。

6. **自动锁定改「永不」**：设置 → 显示与亮度 → 自动锁定 → 永不。⚠️ **屏幕一锁，自动化就停**。手机常插电、亮度调最低。

7. **TikTok 就绪**：登录好账号、能正常刷视频；建议关掉 TikTok 自动更新（换版本可能要重新适配）。

8. **标定本机**（坐标校准）
   - 让 TikTok 停在一条**干净的推荐视频**（右栏点赞/评论/收藏/分享都清晰、无广告无弹窗）→ 切回 autotk →
     点顶部**「标定本机」**（发行版已常显，在「使用说明」旁）→ 提示「✅ 已标定」即可。
   - ⚠️ 换机型 / 点不准 / TikTok 改版后，都回来重标一次。

## B · 手机重启后要做的（每次重启）

WDA 会随重启失效，需重新激活一次（约 1 分钟）：
手机连电脑 → 双击「激活WDA」→ ①激活 → 手机点开 WDA 图标 → 拔线 → autotk 点「启动」。

> 判断 WDA 没起来：autotk 点启动后日志报「连接失败 / 取分辨率失败」，多半就是没激活 WDA。

## C · 交付前必须真机验的测试项（按优先级）

### 🔴 必测（不过就别交付）

**C1 · 发布 8 步锚点（非 iPhone 8 机型未核过）**
- 测什么：给每种目标机型下发一条视频，盯着 autotk 日志走完「发布⓪…⑧」，TikTok 里视频真发出去、发完回推荐流。
- 判过：日志 ⓪~⑧ 齐（其中「发布⑥：填写描述」只在该条视频**带文案**时出现，无文案缺⑥属正常）、TikTok 里真出现这条视频、回到推荐流。
- 判败：日志卡在某步 / 点到「直播」「拍摄」等别处 / 发的不是这条。
- 后果：发布是核心卖点。`devices.json` 里只有 375×667 一档带完整 `publish*`/导航锚点；390×844 那档只标了右栏
  点赞/评论/收藏/分享四键、**没标 publish/导航锚点**，故非 375×667 机型的发布/导航锚点全是比例外推、**极可能点偏**。
  → 每种目标机型都要真机跑一条，偏了就在 `adaptation/devices.json` 里按该机型补 `publish*` 锚点。

**C2 · 各页面导航锚点（非 iPhone 8 机型未核过）**
- 测什么：跑连续养号，肉眼确认「切关注流 / 进搜索 / 进个人主页 / 发评论回复 / 返回推荐流」都点到正确元素。
- 判过：各页切换无误点、评论回复真发出。
- 判败：切页失败 / 点空 / 回复没发出去。
- 后果：followTab/searchIcon/replyEntry 等锚点同样只在 iPhone 8 量过；非标定机型上搜索/关注打粉/主页三模块会静默失灵。

**C3 · 整夜无人值守保活（产品核心承诺）**
- 测什么：TikTok 登好、标定好 → 点启动 → 锁屏或切后台 → **放一整夜** → 早上看日志。
- 判过：早上日志时间戳连续、互动数持续在涨。
- 判败：日志停在夜里某点、互动数不涨。
- 后果：挂机养号若整夜会停，等于产品不成立，且这是买家第一晚就会发现的。前提是定位=「始终」且是含原生模块的 Release 包。

**C4 · 本地网络授权弹窗（app.json 已配文案，需真机验点允许后能连）**
- 测什么：全新装机首次开 autotk 连管理中心 → iOS 弹「查找并连接本地网络设备」→ 确认**有中文文案** → 点允许。
- 判过：弹窗有文案；点允许后设备出现在电脑管理中心设备页、能收发布、能 LAN 下视频。
- 判败：弹窗无文案（买家易点拒绝）/ 点允许后仍连不上。
- 后果：点了「不允许」→ 连不上电脑、收不到发布任务，且极难自查（要进设置→隐私→本地网络手动开）。

### 🟠 应测

**C5 · 发布权限自动点「允许」（新号首发才暴露）**
- 测什么：用一个**从没授过权限的新 TikTok 账号/新机**发一条，看相机/麦克风/相册弹窗是否被自动点「允许」。
- 判过：日志有「关闭系统弹窗 → 点『好/允许访问所有照片』」，三类权限都放行、发布继续。
- 判败：卡在某个权限弹窗不动（尤其英文系统 / TikTok 换了措辞）。
- 后果：卖家自测机常已授过权，极易漏测，到买家新机才炸。

**C6 · 评论 OCR 回复对齐**
- 测什么：开 postReplies，进一条有多条评论的视频，看日志「评论解析：N 条」与实际是否符、回复是否 @ 到对的人、真发出。
- 判过：解析条数合理、回复 @ 对作者且发出。
- 判败：条数明显不符 / 回复串行 / 没发出。
- 后果：打粉核心动作是「命中关键词回复引流」，点错行=话术发给错的人。

**C7 · 直播卡跳过**
- 测什么：推荐/关注流刷到真直播卡，确认日志出「直播卡，跳过」、直接下滑，不点赞不进评论不进直播间；中英两种界面各验。
- 判过：直播卡被识别并跳过。
- 判败：在直播卡上点了赞 / 进了直播间。
- 后果：误入直播间会产生异常互动甚至误触送礼，既伤拟人度又可能实际损失。

**C8 · 三条自愈路径**
- 测什么：分别制造 ① WDA 崩溃/重启（看引擎是否自己重建会话继续，而非整夜卡 404）；② 长文案/短文案视频交替
  （看右栏赞/藏/评/享是否都点准、不点空）；③ 触发已知浮层（好友新作品通知/虚拟头像/奖励政策，看能否自动关）。
- 判过：会话自己重建继续跑、四个动作不点空、浮层被自动关。
- 判败：整夜卡 404 / 点空 / 浮层卡住不动。
- 后果：任一自愈失效都会让整夜挂机在某点静默卡死。

**C9 · 激活踢下线（需真 license 部署）**
- 测什么：激活一台 → 在 license 后台 revoke（删设备）→ 计时看多久被弹回激活页；再断网确认不被误踢。
- 判过：≤30 分钟（心跳周期）被踢回激活页；断网时不误踢（离线宽限）。
- 判败：永不被踢 / 断网也踢。
- 后果：卖家靠踢下线做售后管控（换机解绑、防盗用），失效=授权管控形同虚设。

**C10 · 管理中心真机联动**
- 逐项验：① 同网自动发现或扫码连上；② LAN 直传下载视频；③ 批量修改设置下发后手机即时生效；
  ④ 定时发布：设个未来时间 → 关掉管理中心再开 → 到点仍发出（跨重启不丢）；⑤ 发布完回推荐流；
  ⑥ 多台默认同名（都叫 iPhone）时发布页有**重名告警**、改名后视频文件夹一并改名。
- 判败任一项：对应功能在买家现场不可用。

### 🟢 有空测

**C11 · OTA 真机热更（更新服务器已部署 + 首个包已带 OTA 时）**
- 测什么：改一处 JS → `expo export` → 传到更新服务器 → 手机**冷启动** autotk → 看是否变成新版。
- 判过：冷启动后行为变成新版本。
- 判败：一直是旧版（多半更新服务器路径/域名/签名不对，或 runtimeVersion 不匹配）。
- 后果：不影响当次交付（OTA 是后续修 bug 用），但这是唯一能确认「OTA 真能生效」的方式。

## D · 交付给买家时也要讲清的（写进/口头强调）

- 账号安全看**网络环境**：大量手机挂同一宽带出口，TikTok 可能批量识别。软件做拟人化但**不保证不封号**，多台请自备网络分散方案，先用小号试跑。
- 不要删：手机上的 WDA、描述文件、设置里的开发者信任。
- 电脑管理中心不用时可关，手机独立运行不受影响；但**定时发布期间电脑要开着**。
- 遇任何不确定：先点「停止」，截图日志，联系卖家。
