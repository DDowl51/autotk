## 一、这套系统由什么组成

| 部分 | 装在哪 | 干什么 |
|---|---|---|
| **autotk** | 每台手机 | 养号引擎 + 设置界面（启动/停止、改参数、看日志） |
| **WDA** | 每台手机 | 底层驱动（黑屏小工具，autotk 靠它操作 TikTok），平时不用管 |
| **管理中心** | 一台电脑 | 同时看所有手机的状态、批量改设置、批量发视频 |

日常你只碰两样：手机上的 **autotk**、电脑上的**管理中心**。

## 二、每台手机的一次性设置（装机时做一遍）

新手机由卖家装机（或按第六节自助装机）。装好后逐项检查：

1. **TikTok**：登录好账号，语言用中文或英文，能正常刷视频。
2. **自动锁定改成「永不」**：设置 → 显示与亮度 → 自动锁定 → 永不。
   ⚠️ 这条最重要——**屏幕一锁，自动化就停了**。手机常插电、亮度调最低即可。
3. **激活 autotk**：打开 autotk → 输入激活码 → 激活。激活一次永久记住（换机需新码）。
4. **授定位权限**：第一次点「启动」会弹定位授权，**必须选「始终允许」**
   （这是后台保活的手段，不开的话 App 一进后台就停）。
   如果当时点错了：设置 → 隐私与安全性 → 定位服务 → autotk → 改成「始终」。
5. **标定本机**：打开 TikTok 停在一条**干净的推荐视频**上（右侧点赞/评论按钮清晰可见），
   切回 autotk → 点「**标定本机**」→ 提示成功即可。此后不用再标。

## 三、日常使用（手机端）

- **启动养号**：确认 WDA 在跑（见第五节）→ 打开 autotk → 点「启动」。
  手机会自动切到 TikTok 开始刷视频、点赞、评论——**这是正常现象，别去碰屏幕**。
- **停止**：把 autotk 切回前台 → 点「停止」→ 按钮变「停止中…」，几秒内收尾完成。
- **改参数**：各标签页（推荐页/搜索页/关注监控/时间…）改完即时生效；
  每页有「克制 / 自然 / 频繁」三档预设，不确定就用「自然」。
- **运行期间手机不要干别的**：不要手动刷 TikTok、不要锁屏、不要退 autotk 的登录。

## 四、管理中心（电脑端）

1. **连接手机**：打开管理中心，同一 WiFi 下手机自动出现在「设备」页；
   没出现就打开手机 autotk 扫管理中心「设置」页里的二维码。
   ⚠️ 手机和电脑必须在**同一个 WiFi**，且路由器不能开「AP 隔离/访客网络」。
2. **看状态**：设备页能看每台手机在线/运行/电量/今日互动数，点行进详情看实时日志。
3. **批量改设置**：勾选多台 → 「批量修改设置」→ 改完下发，手机即时生效。
4. **批量发视频**：
   - 设置页选一个**视频总文件夹**；里面按**设备名**建子文件夹，每个子文件夹放要发的视频；
   - 「发布」页扫描后，每条视频可单独设**发送时间**（留空=立即；有「错峰」一键分散时间）；
   - 到点电脑自动下发，手机自动下载并发布，进度逐步回显。
   ⚠️ 定时发布依赖**电脑保持开机**、手机保持解锁状态。

## 五、手机重启了怎么办（重要，必读）

手机重启后 WDA 会停掉，需要**重新激活一次**（约 1 分钟）：

1. 手机用数据线连到管理电脑；
2. 双击运行电脑上的「**激活WDA**」工具（卖家已放在桌面），等它提示完成；
3. 在手机上**点开 WDA 图标**（出现黑屏或两行英文=正常），回到桌面；
4. 拔线，打开 autotk 点「启动」即可。

> 判断 WDA 是否在跑：autotk 点「启动」后如果日志报「连接失败/取分辨率失败」，多半就是 WDA 没起来。

## 六、新手机装机 / 重装（自助）

1. 用手机 Safari 打开装机页：〖https://install.你的域名.com/ota/autotk〗
2. 点「**第一步：开始登记**」→ 按提示安装描述文件（设置里会弹出）；
3. 回到装机页等几秒，「**第二步：安装 autotk**」按钮亮起 → 点它安装；
4. 首次安装需要：设置 → 通用 → VPN与设备管理 → **信任开发者**；
   设置 → 隐私与安全性 → **开发者模式** → 打开并重启。
5. WDA 同理在装机页安装。装完做第二节的一次性设置。

**软件升级**走同一个装机页：重新做第 1–3 步即可**原位覆盖**升级，数据和激活都保留。

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| 手机头部显示「未连接控制中心」 | 手机照常独立运行，不影响养号。要连上：确认同一 WiFi、关 AP 隔离，或重新扫码。 |
| 点赞/评论点不准、点到别处 | TikTok 界面变了或换了手机。打开 TikTok 停在干净视频页 → autotk 点「**标定本机**」。 |
| TikTok 更新后行为异常 | 先点「停止」，联系卖家（可能需要更新适配）。建议关掉 TikTok 自动更新。 |
| 发布视频显示 failed | 点开设备详情看日志停在「发布①~⑧」哪一步，截图发给卖家。 |
| 启动后没反应/连接失败 | WDA 没在跑 → 按第五节重新激活 WDA。 |
| WDA 点开就闪退 | 多半是签名到期（一年一续）→ 联系卖家，从装机页重装即可。 |
| 手机发烫/掉电快 | 正常现象（屏幕常亮+持续运行）。保持插电，环境别太热。 |

## 八、必须知道的注意事项

1. **账号安全预期**：本软件做的是拟人化操作，但 TikTok 风控还看**网络环境**——
   大量手机挂同一个宽带出口、同一 WiFi，平台可能批量识别。多台运营请自行准备网络分散方案
   （每台独立代理/流量卡等），账号权重、内容质量也是你自己的运营范畴。
   **软件不能保证不封号**，请用小号先试跑。
2. **不要删** 手机上的 WDA、描述文件、以及「设置→VPN与设备管理」里的开发者信任。
3. **激活码一码一机**（除非购买多设备码）。换机/刷机后需要新码或联系卖家解绑。
4. 电脑管理中心**不用时可以关**，手机独立运行不受影响；但**定时发布**期间电脑必须开着。
5. 遇到任何不确定的情况：先点「停止」，截图日志，联系卖家：〖联系方式〗。
