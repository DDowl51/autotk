## 二、卖家要部署的 4 个服务（都在你自己的 VPS）

| **Hub** | 管理中心看设备/批量配置/发视频 | **内嵌桌面管理中心**，随 electron 启动自动起——**无需单独部署** | 局域网（买家手机同 WiFi 连） | —（内嵌） | 根 CLAUDE.md 管理中心段 |

> 不需要公网 Hub。（telemetry-collector 是可选的卖家侧遥测，买家侧无关，可不部署。）

## 三、域名 / DNS / 端口清单

三个子域名各自 DNS 指向对应 VPS，放行 80/443（Caddy 自动签证书）：

| 子域名 | 指向 | 改哪个 Caddyfile 占位 |
|---|---|---|
| `license.你的域名` | license 服务器 | license-部署手册.md §3 内联 Caddyfile |
| `install.你的域名` | 装机台服务器 | `services/signing-station` 的 Caddyfile |
| `updates.你的域名` | 更新服务器 | `services/update-server/Caddyfile` |

三处 Caddyfile 里都有 `你的域名 / example.com` 占位，**逐个换成真实域名**，否则该服务签不到证书、买家该入口打不开。

## 四、凭据清单（准备好、别提交、别整目录打包给买家）

| 凭据 | 从哪来 | 放哪 | 备注 |
|---|---|---|---|
| Apple ASC API key（`.p8` + issuerId + keyId） | Apple 开发者后台 | `services/signing-station/data/secrets/` | 装机台自动注册设备/管理描述文件用 |
| 重签证书（`.p12` + 口令） | Apple 证书 → openssl 转（见 WDA_STANDALONE.md 付费段） | `services/signing-station/data/secrets/` | ad-hoc 重签用 |
| license `JWT_SECRET` | `openssl rand -hex 32` | license 服务器 `.env` | **不设/用默认值服务会拒绝启动** |
| license 产品 `key` / `secret` | license 后台建 autotk 产品（secret 只显示一次） | 回填手机 `.env` + 抄进密码管理器 | secret 丢＝重置＝所有已发包失效 |
| OTA 代码签名 `private-key.pem` | Mac `npx expo-updates codesigning:generate`（见部署清单 4.2） | `services/update-server/data/secrets/` | 对应的 `certificate.pem` 打进 App |

> ⛔ 这些全被 `.gitignore` 挡在 git 外，但**「zip 整个工作区目录」会绕过 gitignore** → 私钥泄漏。
> 交付只给买家 IPA（走装机台）+ 管理中心包，**别把仓库目录打包**。详见 [交付日操作手册](交付日操作手册.md) 红线。

## 六、桌面管理中心：打成安装包（已接 electron-builder）

已接好 electron-builder + esbuild：主进程连同 `@mc/hub`/`@mc/publisher`/`@mc/shared` 打成一个自包含 bundle
（绕开 pnpm 软链打包坑），出 Windows NSIS 安装包。**在一台 Windows 上**：

```bash
pnpm install                                   # 首次（会拉 electron-builder，较大）
pnpm --filter @mc/shared build                 # 三个 workspace 包先出 dist（供 bundle 引用）
pnpm --filter @mc/hub build
pnpm --filter @mc/publisher build
pnpm --filter @mc/desktop dist                 # = build renderer + bundle main + electron-builder --win
# 产物：apps/desktop/release/TKManager-Setup-<版本>.exe  ← 发给买家双击安装
```

> 想快速验证不出安装包：`pnpm --filter @mc/desktop pack`（出 `release/win-unpacked/`，直接跑里面的 exe 冒烟）。
> ⚠️ **首次打包 electron-builder 会下载 electron/nsis 资源（上百 MB），需要网络**；打完在 Windows 上
> **实际装一次、跑一次**确认能起（内嵌 Hub、看设备、发视频）——这一步只能在真 Windows 上验。
>
> 开发期照旧 `pnpm --filter @mc/desktop dev:renderer` + 另开 `electron`（用 `electron/main.cjs`，不打包）。

## 七、买家电脑的「激活WDA」工具（手机重启后要用）——已做成零安装 exe

手机每次重启后要激活一次 WDA。已打包成**完全自包含的 exe**（Python + pymobiledevice3 + 全部依赖都在里面），
**买家电脑什么都不用装，双击即用**。详见 `apps/mobile/tools/README-激活WDA.md`。

卖家侧：在一台装了 Python 的 Windows 上双击 `apps/mobile/tools/build-激活WDA.bat` → 出 `dist\ActivateWDA.exe`
→ 拷到买家桌面、重命名「激活WDA」。**不需要 go-ios**（挂镜像用 pymobiledevice3；装 WDA 走装机台）。

> 买家用法：连手机 → 双击「激活WDA」（自动弹 UAC，点是）→ 点「① 激活手机 WDA」→ 等 ✅ →
> 手机上点开 WDA 图标 → 拔线 → autotk 启动。买家电脑**无需 Python / pip / go-ios**，但**需一次性装 iTunes 或「Apple 设备」App**（提供苹果 USB 驱动 Apple Mobile Device Service，任何 iOS 工具连手机的前提，无法塞进 exe；不装则只弹「读取照片」、不弹「信任此电脑」）。
> ⚠️ 卖家打完 exe 后，务必在一台**没装 Python 的干净 Windows** 上双击测一次（冻结 pymobiledevice3
> 偶尔缺 hidden import，报错就按 README 加 `--collect-all <模块>` 重打）。
