## 二、卖家要部署的 4 个服务（都在你自己的 VPS）

## 三、域名 / DNS / 端口清单

三个子域名各自 DNS 指向对应 VPS，放行 80/443（Caddy 自动签证书）：

| 子域名 | 指向 | 改哪个 Caddyfile 占位 |
|---|---|---|
| `license.你的域名` | license 服务器 | license-部署手册.md §3 内联 Caddyfile |
| `install.你的域名` | 装机台服务器 | `services/signing-station` 的 Caddyfile |
| `updates.你的域名` | 更新服务器 | `services/update-server/Caddyfile` |

三处 Caddyfile 里都有 `你的域名 / example.com` 占位，**逐个换成真实域名**，否则该服务签不到证书、买家该入口打不开。

## 四、凭据清单（准备好、别提交、别整目录打包给买家）

| 凭据 | 从哪来 | 放哪 | 备注 |
|---|---|---|---|
| Apple ASC API key（`.p8` + issuerId + keyId） | Apple 开发者后台 | `services/signing-station/data/secrets/` | 装机台自动注册设备/管理描述文件用 |
| 重签证书（`.p12` + 口令） | Apple 证书 → openssl 转（见 WDA_STANDALONE.md 付费段） | `services/signing-station/data/secrets/` | ad-hoc 重签用 |
| license `JWT_SECRET` | `openssl rand -hex 32` | license 服务器 `.env` | **不设/用默认值服务会拒绝启动** |
| license 产品 `key` / `secret` | license 后台建 autotk 产品（secret 只显示一次） | 回填手机 `.env` + 抄进密码管理器 | secret 丢＝重置＝所有已发包失效 |
| OTA 代码签名 `private-key.pem` | Mac `npx expo-updates codesigning:generate-keypair` | `services/update-server/data/secrets/` | 对应的 `certificate.pem` 打进 App |

> ⛔ 这些全被 `.gitignore` 挡在 git 外，但**「zip 整个工作区目录」会绕过 gitignore** → 私钥泄漏。
> 交付只给买家 IPA（走装机台）+ 管理中心包，**别把仓库目录打包**。详见 [交付日操作手册](交付日操作手册.md) 红线。

## 六、桌面管理中心：怎么构建 + 启动（当前无安装包）

`apps/desktop` 还没有 electron-builder，**产不出双击安装包**。当前可行方式：卖家在一台 Windows 上
按下面构建好，再把整个目录（含 `node_modules` 与各 `dist`）打成 zip / 配好机器交付给买家。

```bash
# 首次：装依赖
pnpm install
# 构建各 dist（前三个出 CJS dist 供 electron 主进程 require，最后一个出 renderer dist 供生产 loadFile）
pnpm --filter @mc/shared build
pnpm --filter @mc/hub build
pnpm --filter @mc/publisher build
pnpm --filter @mc/desktop build
# 启动（生产模式，无需 VITE_DEV_SERVER_URL）
pnpm --filter @mc/desktop electron
```

> 缺任一 `build` → electron 主进程 `require('@mc/hub')`/`require('@mc/publisher')` 失败、或加载不到 renderer dist 白屏。
> **交付后第一批工作**：接 electron-builder 出安装包 + electron-updater 自动更新（见远程更新方案 ④）。

## 七、买家电脑的「激活WDA」工具（手机重启后要用）

买家手册 §5 让买家「双击激活WDA」，实际对应 `apps/mobile/tools/activate_wda.py`
（挂开发者镜像 + 拉起 WDA 到 :8100，见 `WDA_STANDALONE.md` 第三段）。**它是 Python 脚本，不是双击 exe**。
卖家交付前要在**买家的电脑**上：

1. 装 Python + `pip install -U pymobiledevice3`、装 `go-ios`；
2. 放好 `activate_wda.py`；
3. 包一个双击入口（`.bat`：`python activate_wda.py`）放桌面，命名「激活WDA」。

> **交付后第一批工作**：把这套打成买家真正能双击、无需装 Python 的工具。当前必须卖家逐台配好，否则
> 手机每次重启后 WDA 起不来、autotk「启动」就连接失败。
