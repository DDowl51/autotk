🌐 服务器

Web UI (React)

数据库
每台电脑可连多台手机 · 支持 USB + WiFi · 管理后台可部署本地或云端

优势

  • 电脑算力强，AI 不受手机限制
  • 一机控多设备，成本最低
  • Web 后台可远程管理
  • TypeScript 全栈统一

劣势

  • 需电脑常驻运行
  • USB/WiFi 断连需容错
A

桌面 Agent 模式

🖥 电脑端（全部逻辑）
Node.js 引擎 · 调度器 · AI · 管理后台
⇅
📱 iOS
WDA 被动执行
📱 Android
ADB 被动执行

优势

  • 架构简单，所有逻辑集中
  • 手机零负担

劣势

  • 断连即停，容错差
  • 手机不强依赖即可
B

纯手机端模式

📱 手机端（全部逻辑）
Node.js (Termux/iSH) · 引擎 · AI · 管理后台
⇅
🖥 电脑
仅浏览器访问管理后台

优势

  • 无需电脑常驻
  • 移动性强

劣势

  • 手机算力受限，AI 推理困难
  • Node.js 在手机端稳定性和生态差（Termux 仅 Android）
  • iOS 基本不可行
