自动化运行时的浮层提示

在 TikTok 上方显示一个半透明浮层，提醒"正在运行"并告知退出方式

技术方案：iOS 悬浮窗
React Native 自身的 View 无法跨越到其他 App 上方，需要借助一个原生模块创建一个高优先级的 UIWindow
UIWindow.level = .alert + 1
比系统弹窗还高的层级，保证浮层始终显示在 TikTok 之上
方案： 写一个小型原生 Swift 模块 → 暴露给 RN

OverlayManager.show(config)
→ 创建一个透明 UIWindow
→ windowLevel = UIWindow.Level.alert + 1
→ rootVC.view 放一个半透明 View

OverlayManager.update(text)
→ 更新文字内容

OverlayManager.hide()
→ 移除浮层窗口
手机屏幕示意
—— TikTok 视频播放中 ——
🤖 自动化运行中
长按右上角退出
⚠️ 音量键 ↑↑↓ 停止自动化
