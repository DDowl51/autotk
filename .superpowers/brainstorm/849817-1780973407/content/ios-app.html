纯 iOS 端方案：React Native + WDA

所有自动化逻辑跑在一个 React Native App 中，直接调 WDA 的 localhost API

架构：一个 App 搞定一切
📱 iPhone
🧠 我们的 App
React Native (TypeScript)
┣ 任务调度引擎
┣ AI 评论生成 (API调用)
┣ 决策逻辑
┣ SQLite 本地存储
┗ 管理 UI（参数配置/日志）
🤖 WDA
WebDriverAgent (XCUITest)
┣ 接收 HTTP 指令
┣ 执行点击/滑动/输入
┗ 返回截图/元素树
← HTTP (localhost:8100) →
📡 我们的 App → WDA (驱动 TikTok) → AI API (生成评论) → WDA (写入评论)

关键技术点

✅ 可行

  • React Native 原生支持 TypeScript
  • WDA 暴露 REST API，RN 端直接 fetch('http://localhost:8100/...')
  • AI 调用：fetch 调 Claude/GPT API
  • 本地存储：react-native-sqlite-storage
  • 后台保活：利用定位服务后台模式（原版也是这么做的）

⚠️ 需处理

  • WDA 需单独安装激活（Xcode sideload 或签名服务）
  • 每次 iPhone 重启需重新激活 WDA
  • iOS 后台限制严格，需用定位 trick 保活
  • WKWebView/RN 对 localhost HTTP 可能有 ATS 问题（配 Info.plist 可解决）
  • 不同 iPhone 机型/TikTok 版本的元素坐标需适配
